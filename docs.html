Dos aplicaciones, un solo repositorio

El repositorio contiene una experiencia Cosmos sin dependencias de runtime (js/, Canvas 2D + WebGL 1) y una escena cinematográfica construida con Vite y Three.js (src/). Ninguna de las dos rutas rompe a la otra: comparten dominio, no código.

Comandos

npm install          # dependencias de construcción (solo para src/)
npm run build        # genera dist/ con Vite
npm test             # suite completa con el runner nativo de Node
npm run lint         # ESLint sobre la experiencia Cosmos y las herramientas
npm run verify       # encoding + enlaces + HTML + tests + build

La experiencia Cosmos no necesita npm install: se sirve como estático. Basta con SERVE_ROOT=1 node serve-dist.mjs o cualquier servidor de ficheros.

Arquitectura de la experiencia Cosmos

Render

js/renderer.js compila ocho programas GLSL propios sobre un preludio compartido. Si el contexto WebGL no existe, se pierde o el shader no compila, dibuja en un canvas 2D independiente con estrellas y gradientes deterministas.

Cámara

js/camera.js combina deriva cinematográfica, órbita y vuelo libre. La rueda, el pellizco y el teclado comparten los mismos límites de zoom.

Calidad

js/quality.js decide perfil (eco/high/ultra) y FPS objetivo; degrada con batería baja, saveData o ventanas sostenidas por debajo de 26 FPS.

Estado

js/state.js guarda solo presentación (mundo, idioma, calidad, filtros) en localStorage, con saneado de cada campo y URL compartible.

Audio

js/audio.js sintetiza un acorde a 432 Hz con osciladores. Nunca suena sin gesto del usuario y se suspende con la pestaña oculta.

Idiomas

js/i18n.js cubre portugués, español, inglés y catalán con validación de claves al arrancar.

Herramientas internas

Cada herramienta acepta --help y un modo --check que devuelve código de salida distinto de cero cuando hay trabajo pendiente, para poder encadenarse en integración continua.

Despliegue

La publicación se hace por GitHub Pages desde la rama de despliegue del repositorio. La experiencia Cosmos vive en la raíz del sitio; los capítulos originales conservan sus rutas galaxias/galaxia-01.html … galaxia-50.html sin cambios, y el antiguo punto de entrada galaxias/omega/index.html redirige a la raíz preservando ?lang= y ?world=.

La escena Vite se publica como artefacto estático independiente (npm run build → dist/). No se publica ningún secreto: el repositorio no contiene claves ni endpoints privados.
