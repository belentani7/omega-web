Privacidad · sin analítica, sin cuentas, sin cookies de terceros

No hay servidor que recuerde tu visita

El sitio es estático: no existe backend propio, ni formularios, ni sistema de cuentas. Todo lo que el universo recuerda de ti se queda en tu navegador y puedes borrarlo en cualquier momento.

Qué se guarda y dónde

Clave localContenidoPara qué
belentani_omega_cosmos_v2Mundo actual, idioma, calidad de render, filtros y mundos visitadosRestaurar la sesión de la experiencia Cosmos
omega_storyNúmeros de los capítulos clásicos ya leídosMarcar progreso en las 50 galaxias
omega_langCódigo de idioma (pt, es, en, ca)Mantener el idioma entre capítulos
omega_senseÍndice de la paleta «sentido» (0–4)Conservar la variante visual elegida

Son datos de presentación. No contienen nombre, correo, ubicación ni identificadores publicitarios. Si el navegador bloquea el almacenamiento, la experiencia sigue funcionando con valores por defecto.

Qué no ocurre

  • No se carga ninguna etiqueta de analítica ni píxel publicitario.
  • No se usan cookies de terceros ni se incrustan reproductores externos.
  • No hay llamadas a servicios de audio o de imágenes: el sonido se sintetiza con osciladores locales y los mundos son shaders procedurales.
  • No se envía a ningún servidor el estado del universo ni el progreso de lectura.
  • No se piden permisos de cámara, micrófono, notificaciones ni ubicación.

Peticiones de red reales

Al abrir el sitio, el navegador solicita únicamente documentos, hojas de estilo y módulos JavaScript del mismo dominio. La escena de src/ descarga sus modelos glTF desde el propio sitio. Los enlaces marcados como externos (GitHub, belentani.es y los productos del pie) solo se abren si decides pulsarlos.

Borrar el estado local

Desde la consola del navegador puedes eliminar todo lo guardado por el universo:

['belentani_omega_cosmos_v2', 'omega_story', 'omega_lang', 'omega_sense']
  .forEach(key => localStorage.removeItem(key));

También puedes usar la opción «borrar datos de sitio» de tu navegador; el resultado es idéntico.

Alojamiento

El sitio se publica con GitHub Pages bajo el dominio belentani.es. Como cualquier proveedor de alojamiento, GitHub registra las peticiones HTTP necesarias para servir los ficheros; ese tratamiento se rige por la política de privacidad de GitHub y queda fuera del control de este proyecto.

Contacto

Para cualquier duda sobre datos o para solicitar la retirada de contenido, abre una incidencia en github.com/belentani7/omega-web/issues o escribe a través de belentani.es.
